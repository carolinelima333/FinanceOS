# FinanceOS

Sistema de controle financeiro pessoal desenvolvido para auxiliar no gerenciamento de receitas, despesas e acompanhamento financeiro.

## Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Dashboard financeiro
- Controle de parcelas
- Relatórios e indicadores
- Interface moderna e responsiva
